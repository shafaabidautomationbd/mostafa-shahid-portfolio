# MD. Mostafa Shahid — Engineering Portfolio

A static HTML, CSS and JavaScript portfolio designed for GitHub and Cloudflare Pages.

## Files
- index.html — page structure
- styles.css — responsive styling
- script.js — interactive skill and project cards
- reports/ — achievement PDFs (upload the three supplied PDF files here)

## Run locally
Open index.html in a modern browser.

## Deploy on Cloudflare Pages
1. In Cloudflare, open Workers & Pages and create a Pages project.
2. Connect this GitHub repository.
3. Use the static site / no framework preset.
4. Leave the build command blank and set the output directory to the repository root (/).
5. Deploy, test the generated pages.dev address, then configure a custom subdomain.

## Important
The project cards are summaries, not independent claims of company endorsement. Confirm permission before publicly publishing confidential company screenshots or reports. Review all dates, role descriptions and contact information before going live.
